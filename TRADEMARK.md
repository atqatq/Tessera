# Trademark policy for the name "Tessera"

The Apache-2.0 licence governs the code — all of it, with no added
conditions. The **name** is a different thing: "Tessera" is the
project's trademark, protected the same way Rust, Linux, Kubernetes,
and PostgreSQL protect theirs. This file states what that means in
plain terms.

## What you may do without asking

- **Nominative use — telling the truth.** Say "built with Tessera",
  "Tessera-compatible", "powered by Tessera", "we migrated from
  Tessera" wherever it is true. Naming the project to identify it is
  always fine, including in commercial products and marketing.
- **Interop statements.** "Works with Tessera", "imports Tessera
  ledgers", and similar compatibility claims are fine when true.
- **Forks.** Fork the code freely under Apache-2.0. A fork must rename
  its distribution: the name "Tessera" identifies *this* project and
  its releases, not someone else's build of it. (Same rule as every
  browser that is not named Chrome but is honest about Chromium.)
- **Discussion, scholarship, critique.** Reviews, papers, courses,
  and blog posts naming the project are fine, flattering or not.

## What is reserved

- Presenting a fork, rebrand, or derivative **as Tessera**, or as an
  official release of this project.
- Using the name in a way that implies endorsement, certification, or
  partnership by the project where none exists.
- Registering domains, logos, or companies that trade on the name in
  the project's space.
- Any use that would confuse a reasonable user about where the
  software came from.

## The distinction that matters

You cannot strip the licence's grant, and nobody can force you to add
conditions to it. Equally, the licence never granted the trademark:
Apache-2.0 §6 says so explicitly. Code: Apache-2.0. Name: this policy.
That split is what lets corporate legal teams approve adoption in an
afternoon.

## Questions and enforcement

Trademark questions and reported misuse:
[@atqatq](https://github.com/atqatq) or a private security advisory
for anything sensitive. The project's goal is honesty about origin,
not royalties or control over truthful speech.
