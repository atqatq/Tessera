# Code of Conduct

## Our standard

Be rigorous and kind. We debate designs, vectors, and tradeoffs — never
people. Harassment, trolling, personal attacks, and bad-faith
AI-generated drive-by PRs are unwelcome.

## Scope

Applies to the repository, issues, PRs, Discussions, any chat spaces,
and events where the project is represented.

## Enforcement

Report privately — **do not open a public issue**:

- **Primary contact:** the maintainer, [@atqatq](https://github.com/atqatq),
  via a private message or a private security advisory (encrypted in
  transit, private by default).
- **If the report concerns the maintainer** — who is, for now, also
  the only reviewer — sending it to the same inbox would make the
  reporter's likely adversary the judge of the report. Until the
  project has a second maintainer or moves to its intended home
  (Eclipse Foundation, whose conduct process applies then), a report
  about the maintainer may be raised with a neutral external party:
  the project recognises the [Contributor Covenant's](https://www.contributor-covenant.org/)
  escalation guidance, and the maintainer commits in writing here to
  accepting an external mediator's review of any such report. Choosing
  the mediator is the reporter's, from a mutually recognised set
  (e.g. a conduct process of a foundation the project has asked to
  join).

Process once a report arrives:

1. Acknowledgement within 72 hours.
2. Review within 7 days, privately, with the reporter kept informed.
3. Enforcement follows the Contributor Covenant v2.1 escalation
   ladder (warning → temporary ban → permanent ban) proportionate to
   the finding.
4. Maintainers are bound by the same rules — enforcement does not skip
   core team.
5. Anonymized quarterly summaries of enforcement activity are published
   once there is any activity to summarize.
