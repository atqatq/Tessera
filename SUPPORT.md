# Support

Realistic expectations, stated up front. This project has **one
maintainer today**; pretending otherwise would be the first dishonest
claim in a repo that promises it publishes none.

## Where to ask

| Need | Place | Expected response |
|---|---|---|
| "How do I…", "what if…" | [Discussions](https://github.com/atqatq/Tessera/discussions) (Q&A) | best effort, ~a week; the docs may answer faster — start at the [docs site](https://github.com/atqatq/Tessera/tree/main/docs/site) |
| Bug with a failing test | [Issues](https://github.com/atqatq/Tessera/issues) (bug template) | triage within a week; a reproducing test moves it to the front |
| Security vulnerability | [private advisory](https://github.com/atqatq/Tessera/security/advisories/new) | 72h acknowledgement, 7d triage (see SECURITY.md) |
| Real-time conversation | none yet | the maintainer will stand up a Zulip channel when there is a community to staff it — an empty chat room with a dead badge helps nobody |

## The fastest support path

A failing test. The bug template asks for one because a reproducing
test turns "please look at my weekend" into "please review ten
lines" — and it becomes part of the suite that protects everyone
after you.

## Commercial support

None offered. If a company needs a support contract, that is a
conversation for the maintainers' inbox — and a signal the project
should record in ADOPTERS.md, because sustainability is part of the
governance plan.
